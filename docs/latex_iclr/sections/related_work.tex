\section{Related Work}
\label{sec:related-work}

Prior work addresses three pieces of the problem: what representation to
transfer, how to bridge different widths, and whether to compare coordinates
or coordinate-free structure. We organize the literature along these axes.

\paragraph{Embedding and intermediate-layer distillation.}
Early text-embedding distillation directly regressed student sentence vectors
onto teacher outputs \citep{reimers2020multilingual}. Later methods augment
endpoint transfer with contrastive, relative-geometric, multilingual, or
task-specific objectives
\citep{gao2021distilcse,xu2023distillcse,simtde2023,lealla2023,kim2023embeddistill,zhang2024jasper,li2025ese,leaf}
and with generated or targeted data \citep{lee2024gecko,akram2026jina}. Another
family transfers intermediate representations: EMO aligns token relations and
hidden states, TALAS combines an endpoint anchor with lower-layer
self-distillation, and other methods transfer mixtures of layers or attention
\citep{truong2025emo,talas,vu2026mol,wang2024feature}. Such objectives require
internal access or choices about which layers to supervise, and cross-model
layer correspondence can be fragile
\citep{ko2023revisiting,kim2025layerselection}. GATE-KD instead isolates the
terminal-only setting, using cached final teacher embeddings under the TALAS
data and evaluation protocol (Section~\ref{sec:exp-setup}).

\paragraph{Cross-dimensional representation alignment.}
Learned projectors provide a common space for teacher and student embeddings,
but their parameterization and normalization affect optimization
\citep{hpd,miles2024projector,chen2023projector}. TCS instead obtains fixed
lower-dimensional targets using PCA \citep{tcs}. After reduction, orthogonal
changes of basis preserve inner products, so a representation belongs to an
equivalence class rather than a unique coordinate system
\citep{kornblith2019cka,williams2021shape,maystre2025procrustes}.
\citet{han2026equivalence} formalizes this principle and argues that absolute
coordinates are not teacher content. We begin from the same premise but ask an
optimization question left after rank reduction: which student-relative member
of the equivalence class should serve as the fixed pointwise target?
\citet{bhattarai2025shortcut} remove orientation by minimizing a Procrustes
distance inside the distillation loss. GATE-KD instead selects one corpus-level
representative relative to the initial student and exposes it persistently
during training; Table~\ref{tab:gauge-mechanism} compares the two interfaces.
Unlike Matryoshka learning and MIPIC, which train nested widths within one model
\citep{kusupati2022mrl,huy2026mipic}, our setting transfers an external teacher
whose coordinates and width are unrelated to the student's.

\paragraph{Coordinate-free structural objectives.}
Relational, similarity-preserving, and contrastive distillation transfer
pairwise distances, Gram matrices, or positive--negative relations
\citep{park2019rkd,tung2019similarity,tian2020crd}; related work also imposes
graph- or geometry-aware constraints
\citep{joshi2024representation,burykina2025jdcemb,zhou2026dice}. Persistent
homology provides multiscale summaries of point-cloud structure and has been
used for topological distillation or regularization
\citep{topkd2024,jeon2024topological,heiter2023topological}. For sentence
embeddings, it has primarily been an analysis tool
\citep{das2021tedtalk}. GATE-KD uses sorted degree-zero persistence death times
only as an optional native-space auxiliary; the gauge-fixed endpoint target
provides the primary sample-level supervision.
